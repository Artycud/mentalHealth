# เช็กลิสต์วันบูธ: iPad 1 เครื่อง + ทีวี 1 จอ

สำหรับทีมสภานักเรียนที่ประจำบูธ อ่านจบในหน้าเดียว

## ก่อนวันงาน (ทำครั้งเดียว)

1. เข้า `/admin` → ตั้ง **บูธที่กำลังจัด** เป็นบูธของรอบนี้ (เช่น ลอยกระทง)
2. ใน `/admin` → การ์ด **บัญชีบูธ** → กดสร้างรหัสผ่านใหม่ แล้วจดไว้ (รหัสจะแสดงครั้งเดียว)
3. บน server ตั้ง `PUBLIC_SITE_URL=https://mentalhealth.satitm.chula.ac.th` เพื่อให้ QR บนจอพาไปที่อยู่จริงเสมอ
4. เช็กเวลาบูธใน `/admin` → กิจกรรม ให้ตรงกับที่ประกาศ (ทีวีโชว์เวลานี้)

## เช้าวันงาน

**iPad (เจ้าหน้าที่ถือ)**
- ตั้งค่า → จอภาพและความสว่าง → ล็อกอัตโนมัติ = **ไม่ใช้**
- เปิด Safari ไปที่ `/booth/kiosk` แล้วเข้าสู่ระบบด้วยบัญชีบูธ (อยู่ได้ 12 ชั่วโมง)
- เปิด **Guided Access** (ตั้งค่า → การช่วยการเข้าถึง → Guided Access) แล้วกดปุ่มด้านข้าง 3 ครั้ง เพื่อล็อกให้อยู่หน้านี้
- วางแนวนอน และมีสายชาร์จที่บูธ

**ทีวี** (เรียงจากดีที่สุด)
1. โน้ตบุ๊กต่อ HDMI → เปิด `/booth/display` → กด **เต็มจอ** (หรือ F11) → ปิดโหมดพัก/ประหยัดพลังงานของโน้ตบุ๊ก
2. ถ้าไม่มีโน้ตบุ๊ก: เปิด `/booth/display` จากเบราว์เซอร์ในตัวทีวี
3. ทางสุดท้าย: สะท้อนจอจาก iPad (หน้าจอ iPad ใช้บนทีวีได้ แต่จะไม่มีตัวเลข "กี่ใน 10 คน")

**ลองหนึ่งรอบก่อนเปิดบูธ**
- เล่นบน iPad 1 รอบ → ภายใน ~5 วินาที ดอกไม้ต้องขึ้นบนทีวี
- เอามือถือสแกน QR บนทีวีจากระยะ 2–3 เมตร → ต้องเปิดหน้าแรกของเว็บได้

## ระหว่างบูธ

1. ยื่น iPad ให้นักเรียน ตอบ 4 ข้อ (ข้อที่ 4 คือ "โอเคไหม" ไม่มีผลกับดอกไม้)
2. ดูชื่อดอกไม้บนหน้าจอ แล้วให้ดอกไม้จริง **และคูปองลดไอศกรีม**
3. กด **คนต่อไป** (ถ้าลืม หน้าจอจะกลับหน้าแรกเองใน 45 วินาที)
4. หน้าแรกของ iPad มีบรรทัด **แจกไปวันนี้** บอกว่าแต่ละดอกแจกไปกี่ดอกแล้ว ดูไว้ว่าดอกไหนใกล้หมด

**สำคัญ:** อย่าอ่านออกเสียง ถาม หรือแสดงความเห็นเรื่องคำตอบข้อ "โอเคไหม" ของใคร
หน้าจอตอบนักเรียนเองแล้ว และทุกผลลัพธ์มีช่องทาง CUD Care อยู่แล้ว
ถ้านักเรียนอยากคุยจริงจัง พาไปหา CUD Care

## ถ้ามีอะไรผิดปกติ

| อาการ | ทำอย่างไร |
|---|---|
| **คูปองหมด** | เข้า `/admin` → การ์ด **คูปองของบูธ** → กด **หมดแล้ว** ทีวีและ iPad จะเลิกโชว์คูปองภายในไม่กี่วินาที |
| จุด **สด** บนทีวีเป็นสีเทา | อินเทอร์เน็ตหรือ server หลุด เช็ก Wi-Fi ไว้ จอจะกลับมาเองเมื่อต่อได้ |
| ทีวีขึ้นหน้า error ของเบราว์เซอร์ | กดรีเฟรชหนึ่งครั้ง |
| iPad ขึ้นหน้าเข้าสู่ระบบ | ใส่บัญชีบูธอีกครั้ง (ถ้าใครเพิ่งสร้างรหัสใหม่ในแอดมิน ทุกเครื่องจะต้องเข้าใหม่) |
| เน็ตหลุดระหว่างนักเรียนเล่นบน iPad | เล่นต่อได้ตามปกติ ผลจะขึ้นครบ แค่รอบนั้นอาจไม่ถูกนับบนทีวี |
